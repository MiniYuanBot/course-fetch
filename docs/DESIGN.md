# Course Fetch 界面规范

Course Fetch 是教学网内的录像工具，视觉沿用 PKU Prism：中性色、北大红、清晰的分组和紧凑但可读的表格。保留 Shadow DOM 隔离，不修改教学网样式、链接、表单或下载流程。

## 主题规则

优先级：**当前页面启用的 PKU Prism → Course Fetch 保存的独立偏好 → 系统主题**。

- Prism 的公开接口为根元素上的 `data-pku-prism="enabled"` 与 `data-pku-prism-theme="light|dark"`。只读取这两个属性，不读取 Prism 的内部存储。
- Prism 启用时，外观选择显示「跟随 PKU Prism」，由 Prism 统一切换；Course Fetch 原有独立偏好保持不变。
- 没有 Prism、Prism 被禁用或主题属性无效时，使用独立偏好「浅色 / 深色 / 跟随系统」。默认跟随系统，选择存入脚本自己的 GM storage `appearance`，跨课程和标签页同步。
- 动态监听 Prism 属性、系统主题及自身偏好变更，不刷新页面、不重建面板，不中断输入、选择或下载。
- 同源框架可继承最近一层启用 Prism 的父页面。跨域框架受浏览器隔离限制，使用独立偏好；不通过其他标签页的 Prism 状态猜测当前主题，不扩大脚本匹配范围。
- 只有外观状态参与主题判断，不读取认证信息、视频地址或业务数据。

## 基础变量

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 主表面 | `#FFFFFF` | `#202023` |
| 次级表面 / 表头 | `#F4F4F5` | `#27272A` |
| 边框 | `#E4E4E7` | `#3F3F46` |
| 控件边框 | `#71717A` | `#A1A1AA` |
| 正文 | `#18181B` | `#F4F4F5` |
| 次级文字 | `#52525B` | `#A1A1AA` |
| 链接 / 焦点 | `#9E2533` | `#F0A3AD` |
| 选中背景 | `#FAEEF0` | `#38272D` |
| 主按钮 | `#9E2533` + 白字 | `#9E2533` + 白字 |

- 系统中文字体栈与 Prism 一致。正文 13px / 1.55，辅助文字 12px；文件名用等宽字体，时间和进度用等宽数字。
- 间距采用 4 / 8 / 12 / 16 / 24px；小圆角 4px，控件 6px，面板 8px。
- 用边框区分层级，不使用渐变、毛玻璃、装饰阴影、Emoji 或循环动画。
- 所有颜色通过语义变量引用，包括原生输入框、选择框、选项、勾选框、悬停、禁用、焦点、下载进度、成功、警告和失败。
- 浅深色悬停保持原有文字语义颜色。次级文字对比度至少 4.5:1，输入框轮廓清晰。

## 面板与组件

1. 右下角可折叠标题按钮，保留录像数量与下载进度。支持键盘，使用 `aria-expanded` 表达展开状态。
2. 课程和命名模板在前，长模板变量说明折叠；输出格式与外观组成独立的偏好区。
3. 日期排除与标签保留原有业务操作。主动作「下载选中」用品牌色，其余为中性按钮。
4. 进度与提示区位于操作栏下方，录像表格保持完整文件名、时间、教师和逐条操作。状态不只靠颜色表达。
5. 桌面面板宽 760px，受视口宽高约束。窄屏使用 8px 安全边距，偏好区改为单列；表格只在自身区域横向滚动，配置区可以纵向滚动。
6. 普通控件最小高 32px，标题 44px；触屏主要控件最小高 44px。按钮有 pointer，键盘焦点清晰。

## 验证

- 真实教学网：观察公开主题属性、截图比较面板；只操作折叠和主题，不点击下载、编辑或提交。
- 自动化：主题优先级、启停与动态变更、系统变化、偏好持久化与跨页同步、同源父框架和清理；原有本地下载与 MP4 冒烟继续执行。
- 本地浏览器验证浅深色、窄屏、悬停、禁用、警告、失败、完成和空状态。所有下载验证使用合成的本地数据。

### v0.6.0 验证记录

- `npm test`：136 项通过，包括打包后的 UI 下载回归和主题测试；`npm run check` 与 `git diff --check` 通过。
- Chrome DevTools MCP：在已登录的真实课堂实录页临时挂载只读预览，检查桌面浅深色、390px 触屏布局、Prism 动态同步、独立选择、悬停、禁用、警告和失败样式、键盘折叠及焦点。主题切换保留输入内容和文字选区；窄屏配置区无水平溢出。
- 实测普通悬停、链接、主按钮、警告、错误和次级文字的对比度：浅色最低 5.91:1，深色最低 6.34:1。
- Impeccable 对界面源文件的设计检测无发现。
- `npm run smoke` 的独立 Chrome 下载冒烟因当前环境禁止监听 `127.0.0.1` 而未启动（`listen EPERM`）。浏览器预览没有执行真实下载或业务写入。
