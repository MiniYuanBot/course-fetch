# Course Fetch

Course Fetch 是一个浏览器脚本，可以自动整理并批量下载北大教学网「课堂实录」的录像。

**[一键安装最新版](https://github.com/MiniYuanBot/course-fetch/releases/latest/download/course-fetch.user.js)**（需先完成下面的第一、二步）· [所有版本与更新说明](https://github.com/MiniYuanBot/course-fetch/releases)

打开课程的课堂实录页面，脚本会自动收集整门课的录像，按上课时间排序、统一命名，例如 `L01-2026-09-07-第7-8节.mp4`。勾选需要的录像，点击下载，就能保存为可直接播放的 MP4 文件。

## 为什么用 Course Fetch

- **收集整门课的录像**：自动翻页，合并重复项，按上课时间从 L01 开始编号。
- **统一文件名**：默认 `L序号-日期-第x-x节.mp4`，也可以自定义命名模板，下载后无需手动改名。
- **跳过放假的空录像**：学校有时会在放假期间照常上传空录像，占用一个编号。按日期排除后，后面的录像会自动重新编号。
- **批量下载**：勾选多条录像，选一次保存位置，默认同时下载 3 条。单条失败不影响其它录像，也能取消单条或整个批次。
- **保存为 MP4**：边下载边转换成 MP4，不重新编码，画质和音质与原视频完全一致。文件比原始格式小约 5–10%，系统自带的播放器就能打开。
- **直接写入硬盘**：几 GB 的录像也能边下边存，不占内存，电脑不会因下载变卡。
- **查看下载进度**：显示百分比、已下载大小、速度和预计剩余时间。批量结束后保留每条录像的下载结果，确认后恢复页面。
- **按账号权限下载**：只下载当前登录账号有权观看的录像，不破解、不绕过权限，也不保存账号信息或视频密钥。
- **安装与更新**：通过链接安装，后续版本由 Tampermonkey 自动更新，不需要另装软件。

> 课堂录像的版权归授课教师和学校所有。请仅用于个人学习，并遵守学校的相关规定，不要传播。

## 准备工作

| 项目 | 要求 |
| --- | --- |
| 浏览器 | 电脑版 **Chrome**、**Edge**、**Safari**、**Firefox** 均已支持。Chrome / Edge 可直接写入所选文件夹；Safari / Firefox 会用「浏览器保存」：优先写浏览器临时文件（可并行下载），否则在内存中合并（见[常见问题](#常见问题)） |
| 扩展 | Tampermonkey（油猴），下面会一步步安装 |
| 脚本 | 从 [Releases 页面](https://github.com/MiniYuanBot/course-fetch/releases/latest) 安装，见第三步 |
| 账号 | 能正常登录北大教学网，并且能在网页上播放要下载的录像 |
| 硬盘空间 | 每节课（约 2 小时）的录像约 0.6–1 GB |

## 第一步：安装 Tampermonkey

Chrome 和 Edge 版的 Tampermonkey 可以在扩展商店免费安装。Safari 版由 Mac App Store 官方分发，需**付费购买**，一次性买断。

**Chrome / Edge：**

1. 用 Chrome 或 Edge 打开 Tampermonkey 官网：<https://www.tampermonkey.net/>。
2. 点击对应浏览器的下载按钮，进入扩展商店：
   - Chrome：Chrome 网上应用店
   - Edge：Microsoft Edge 加载项
3. 点击「添加至 Chrome」或「获取」，在弹出的确认框中点「添加扩展程序」。
4. 安装后，点击浏览器右上角的拼图图标，找到 Tampermonkey，点旁边的图钉，将它固定到工具栏，方便以后使用。

**Safari（macOS）：**

1. 打开 Mac 上的 App Store，搜索 Tampermonkey，购买并安装。
2. 打开 Safari 的「设置 → 扩展」，找到 Tampermonkey，勾选启用。
3. 首次使用时，Safari 可能询问是否允许 Tampermonkey 在网站上运行，选择允许即可。

## 第二步：允许 Tampermonkey 运行脚本

新版 Chrome 和 Edge 需要手动开启用户脚本权限。**未开启时，脚本不会生效。** Safari 用户可直接跳到第三步。

**Chrome：**

1. 在地址栏输入 `chrome://extensions` 并回车。
2. 找到 Tampermonkey，点击「详细信息」。
3. 打开 **「允许用户脚本」（Allow User Scripts）** 开关。
   - 如果没有这个开关，说明 Chrome 版本较旧，请打开页面右上角的 **「开发者模式」**。

**Edge：**

1. 在地址栏输入 `edge://extensions` 并回车。
2. 打开左侧（或页面上方）的 **「开发人员模式」** 开关。
3. 找到 Tampermonkey，点击「详细信息」；如果有 **「允许用户脚本」** 开关，也将它打开。

## 第三步：安装 Course Fetch 脚本

**Chrome / Edge / Firefox：**

1. 打开最新版本的 [Releases 页面](https://github.com/MiniYuanBot/course-fetch/releases/latest)。
2. 在页面下方的 Assets 中点击 **`course-fetch.user.js`**，或直接点击[安装最新版](https://github.com/MiniYuanBot/course-fetch/releases/latest/download/course-fetch.user.js)。
3. Tampermonkey 会打开安装页。确认脚本名称为 Course Fetch，并查看版本号，然后点击「安装」。
4. 点击 Tampermonkey 图标 →「管理面板」，确认列表中有 Course Fetch，且右侧开关已开启。

**Safari：**

Safari 版的 Tampermonkey 无法像 Chrome 那样拦截 `.user.js` 链接，点击链接只会下载文件。请使用「从 URL 安装」：

1. 点击 Tampermonkey 图标 →「管理面板」，在左侧选择「实用工具」。
2. 找到「从 URL 安装」，粘贴以下地址：
   `https://github.com/MiniYuanBot/course-fetch/releases/latest/download/course-fetch.user.js`
3. 点击「安装」，在随后弹出的页面上再点一次 **「安装」**。
4. 回到管理面板，确认 Course Fetch 右侧的开关已开启。

以后仍会自动更新，不必重复安装。

> Safari 上**不要把 `.user.js` 文件拖进 Tampermonkey 面板安装**，这会导致中文乱码。请使用「从 URL 安装」，或在面板中新建脚本后粘贴内容。

> **Chrome / Edge 点击链接后直接下载文件，没有弹出安装页？** 说明前两步尚未完成，或 Tampermonkey 没有启用。检查后再次点击安装链接。
> 也可以打开 Tampermonkey 管理面板，在「实用工具 → 从 URL 安装」中粘贴上面的链接。

## 第四步：打开课堂实录，确认脚本已运行

1. 登录 [北大教学网](https://course.pku.edu.cn)，进入一门有录像的课程，点击左侧菜单中的「课堂实录」。
   - 建议从**第 1 页**进入，便于脚本收集全部分页。
2. 稍等片刻，页面右下角会出现 `Course Fetch · 32 条` 小条，数字是录像条数。脚本会自动扫描所有分页，期间显示「扫描中…」。
3. 点击这个小条，展开 Course Fetch 面板。

面板与 **PKU Prism** 使用统一的浅深色样式。当前页面启用 Prism 时自动继承，随 Prism 实时切换；未安装或停用 Prism 时，可以在面板的「外观」中选择「浅色 / 深色 / 跟随系统」，选择会跨课程保存。Prism 启用期间由它统一管理主题，停用后恢复 Course Fetch 的独立偏好。同源框架也能继承父页面；跨域框架使用独立偏好。

首次下载时，Tampermonkey 可能询问是否允许脚本访问 `pku.edu.cn` 下的域名（例如 `resourcese.pku.edu.cn`），请选择「总是允许」。

## 第五步：检查录像列表

面板中各项的含义：

| 区域 | 说明 |
| --- | --- |
| **课程** | 自动识别的课程名。识别得不准可以直接修改，修改后会被记住 |
| **命名模板** | 文件名规则，默认 `L{index:02d}-{date}-第{periodStart}-{periodEnd}节.mp4`，修改后列表中的文件名会实时更新；点「重置」恢复默认 |
| **输出格式** | 默认 **MP4（推荐）**；也可以选 **TS（原始流）**。选择会被记住 |
| **外观** | Prism 启用时自动跟随；否则可选择浅色、深色或跟随系统 |
| **排除日期** | 折叠区域，平时收起。每行一组日期，「排除」只影响当前课程，「存为标签」则对所有课程生效（见下方「排除放假等空回放」） |
| **录像列表** | 按上课时间排序，L01 是最早的一节课。每行有「打开」「复制名」「排除」「下载」四个按钮 |
| **提示** | 如果有解析失败、翻页失败、重复录像等情况，会在这里列出 |

### 排除放假等空回放

学校有时会在放假期间照常上传空录像。它会占用一个编号，使后续录像的编号都往后错一位，例如第 5 次课变成 `L06`。

排除后，该行会变灰，序号显示 `—`，不再参与编号。「全选」「下载选中」「复制清单」「导出 JSON」都会跳过它。仍可单独点击该行的「下载」，确认录像是否为空。

展开默认收起的「排除日期」，填入日期。第一行左侧的「＋」可以添加一行，其余行左侧的「－」可以删除该行。每行处理一组日期，互不影响；右侧的三个按钮作用如下：

| 按钮 | 作用 |
| --- | --- |
| **排除** | 排除当前课程中落在**这一行**日期的录像，按课程记住 |
| **恢复** | 恢复这一行日期对应的条目（由标签排除的要停用或删除标签） |
| **存为标签** | 在这一行下面填个名字（如「中秋节」）再点「保存」，**所有课程**都会自动排除这些日期 |

日期写法：

| 写法 | 含义 |
| --- | --- |
| `2026-10-01` | 单个日期 |
| `2026-10-01~2026-10-07` | 日期段（`~` 也可写成 `～`、`至`、`到`） |
| `2026-10-01 2026-11-02~2026-11-06` | 一行里写多段，用空格或逗号分隔 |

保存的标签列在日期行下方。取消勾选可临时停用，标签仍会保留；点击「删除」则彻底移除。由标签排除的录像会标注标签名（如「中秋节」），停用或删除对应标签即可恢复。

## 第六步：选择下载目录（重要）

无论是单条还是批量下载，首次点击下载时，浏览器都会弹出**「选择文件夹」**窗口，询问是否允许网站查看和编辑其中的文件。脚本会将录像直接写入所选文件夹。

> **不要直接选择系统文件夹**，例如「下载」「文档」「桌面」、整个磁盘（如 C 盘、D 盘的最外层），以及 Windows、Program Files 等系统目录。
> 浏览器出于安全考虑会拒绝或警告：「无法打开此文件夹，因为其中包含系统文件」。
>
> 在选择窗口中进入「下载」等文件夹，点击「新建文件夹」，命名为 `课程录像` 或课程名。然后**选中新建的子文件夹**，点击「选择文件夹」。

浏览器随后会询问「允许 course.pku.edu.cn 编辑文件吗？」，点击「编辑文件」或「允许」。

建议每门课建一个子文件夹，例如 `下载/课程录像/操作系统/`，方便整理。

## 第七步：下载录像

### 单条下载

1. 找到需要的录像，点击该行的「下载」。
2. 选择用于保存录像的子文件夹（见第六步）。
3. 脚本会在后台标签页中短暂打开播放页，获取视频地址后关闭。此时进度区显示「打开播放页，自动捕获播放列表」。
4. 开始下载后，面板顶部会显示：
   - 进度条和 `分片 32 / 150（21%）`；
   - 已下载大小、视频时长、下载速度和预计剩余时间；
   - 收起面板后，右下角小条仍会显示 `下载 21%`。
5. 下载完成后，状态栏显示 `已完成：L03-2026-09-30-第3-4节.mp4（…）`，文件已保存到所选文件夹。

### 批量下载

1. 勾选需要的录像，或点击「全选」。
2. 点击「下载选中」，选择一次保存文件夹（见第六步）。
3. 脚本开始下载所选录像，默认同时下载 3 条，各自保存为独立文件。
4. 进度区显示已处理、成功、失败、取消和排队的数量，以及已写入大小。每行还会显示对应录像的状态和进度。
5. 全部结束后，进度区显示 `批量下载已结束：成功 N · 失败 N · 取消 N`，各行保留下载结果。核对后点击「确定」，面板恢复到下载前的状态。
6. 如有失败的录像，重新勾选，再点「下载选中」重试。

### 取消下载

- **单条下载**：点击进度区的「取消」，或再次点击该行显示百分比的按钮。
- **批量下载**：某行的「取消此条」只取消该条录像；进度区的「取消整个批次」会停止所有未完成的条目。
- 取消后，脚本会删除未下载完的文件，不留下损坏文件。已完成的文件会保留。

> 下载时**不要关闭或刷新课堂实录页面**，否则会中断下载。关闭页面时，浏览器会弹窗提醒。下载期间可以切换到其它标签页。

### 同名文件

文件夹中已有同名文件时，脚本会另存为 `文件名 (2).mp4`，**不会覆盖原文件**。

## 第八步：观看

下载的 `.mp4` 可以用 Windows「媒体播放器」或「电影和电视」、macOS 的 QuickTime、VLC、PotPlayer 等直接播放，也可以拖动进度条。

## 其它实用功能

| 按钮 | 作用 |
| --- | --- |
| **复制清单** | 复制所有录像（勾选了就只复制勾选的）的文件名、时间和教师，可以粘贴到 Excel 或笔记里 |
| **导出 JSON** | 导出整门课的录像清单文件，不包含任何链接或登录信息 |
| **打开选中** | 在后台标签页中打开勾选录像的播放页 |
| **复制名** | 复制该行的文件名 |
| **重新扫描** | 重新读取课堂实录的全部分页，例如老师新上传了录像时使用 |

### 自定义文件名

在「命名模板」中可以使用以下变量：

| 变量 | 含义 | 示例 |
| --- | --- | --- |
| `{index:02d}` | 序号（补零到 2 位）；`{index}` 表示不补零 | `03` |
| `{date}` | 上课日期 | `2026-09-30` |
| `{YYYY}` / `{YY}` / `{MM}` / `{DD}` | 日期的年 / 年后两位 / 月 / 日 | `2026` / `26` / `09` / `30` |
| `{periodStart}` / `{periodEnd}` | 起止节次 | `3` / `4` |
| `{teacher}` | 教师 | `陈向群` |
| `{course}` | 面板中的完整课程名 | `计算概论（B）上机(24-25学年第1学期)` |
| `{courseName}` | 去掉末尾学年学期后的课程名 | `计算概论（B）上机` |
| `{academicYear}` | 学年，保留年份位数 | `24-25` |
| `{semester}` | 学期编号；可用 `{semester:02d}` 补零 | `1` |
| `{time}` | 开始时间 | `1010` |

模板 `{course}-L{index:02d}-{date}.mp4` 的文件名示例是 `操作系统-L03-2026-09-30.mp4`。日期也可以简写：把 `{date}` 换成 `{YY}{MM}{DD}`，例如 `L03-260930.mp4`。文件名中的非法字符会自动替换为 `_`。

课程名也可以拆开使用。以 `计算概论（B）上机(24-25学年第1学期)` 为例，模板 `{courseName}-{academicYear}-S{semester}-L{index:02d}.mp4` 会生成 `计算概论（B）上机-24-25-S1-L03.mp4`。

脚本只拆分末尾表示学年学期的括号，支持中英文括号、两位或四位年份（如 `2024-2025`）。课程名里的 `（B）` 等括号会保留。未匹配到后缀时，`{courseName}` 使用完整课程名，`{academicYear}` 和 `{semester}` 为空。

## 常见问题

**页面右下角没有出现 Course Fetch 小条？**

- 确认已完成[第二步](#第二步允许-tampermonkey-运行脚本)，且 Tampermonkey 管理面板中 Course Fetch 的开关已开启。
- 点击 Tampermonkey 图标，检查当前页面是否有正在运行的 Course Fetch。
- 课堂实录可能嵌在框架中。在录像列表上点右键 →「在新标签页中打开框架」，再到新标签页中使用。

**选择文件夹时提示「包含系统文件」或无法选择？**

不能直接选择「下载」「文档」「桌面」或整个磁盘等系统文件夹。请先在其中**新建一个子文件夹**，再选择它，详见[第六步](#第六步选择下载目录重要)。

**提示「当前浏览器不支持目录写入」？**

这表示当前使用的是 Safari 或 Firefox，或课堂实录页面嵌在框架中。脚本会自动切换到「浏览器保存」，单条和批量下载都支持：

- 优先写入浏览器临时文件（OPFS），支持并行下载。完成后由浏览器保存，不额外占用内存；
- 如果临时文件不可用，就在内存中合并整段视频，再由浏览器保存。批量下载时逐条处理，每条占用的内存约等于视频大小（约 1 GB）。

如果页面嵌在框架中，右键选择「在新标签页中打开框架」即可恢复直接写入所选文件夹。也可以改用 Chrome 或 Edge。

**弹窗提示「自动捕获播放列表超时」？**

这表示脚本在 20 秒内没有获取到视频地址，常见原因是登录已过期，或播放器需要手动点击播放。先在教学网打开这节课，确认能正常播放，再重试下载。

如果仍然失败，按 `F12` 打开开发者工具，在「网络（Network）」标签中搜索 `m3u8`，把出现的请求地址复制到弹窗中。批量下载不会弹出输入框，而是将该条标记为失败；这时可以改用单条下载。

**提示「无权限访问（HTTP 401/403）」？**

登录已过期，或当前账号没有这节录像的权限。请重新登录教学网，确认能播放这节录像后再试。

**提示「…无法无损转为 MP4，已改存为 TS」？**

个别录像的编码格式（例如 H.265）无法原样封装为 MP4。脚本会自动改存为原始的 `.ts` 文件，不重新编码，避免损失画质。`.ts` 可以用 VLC、PotPlayer 等播放器播放。

**提示「第 N 个分片解密失败」或「不是有效的 TS 数据」？**

视频密钥可能已过期。刷新课堂实录页面后重新下载。

**提示「不支持的加密方式」？**

这节录像使用了 DRM 版权保护，本工具不处理。

**列表中的录像数量比实际少？**

脚本从当前页向后收集录像。请回到课堂实录的**第 1 页**，再点击「重新扫描」。

**放假那几天的编号错位了？**

放假时的空录像会占用编号，使后续编号错位。展开「排除日期」，填入对应日期，点击「存为标签」并命名（如「中秋节」），所有课程都会自动排除这些日期的录像并重新编号。只处理当前课程时，点击「排除」，或使用录像行末的「排除」。详见[排除放假等空回放](#排除放假等空回放)。

**怎么更新脚本？**

Tampermonkey 会定期检查更新，默认每天一次，新版本会自动安装。需要立即更新时，点击 Tampermonkey 图标 →「检查用户脚本更新」，或重新点击[安装最新版](https://github.com/MiniYuanBot/course-fetch/releases/latest/download/course-fetch.user.js)。更新时可能需要确认新增权限，请选择允许。

**下载的 `.ts` 文件能转成 MP4 吗？**

可以。电脑上需安装 [Node.js](https://nodejs.org/)（20 或以上版本），再下载本项目源代码（Releases 页面中的 Source code），在项目目录下运行：

```bash
npm run ts2mp4 -- "L01-2026-09-07-第7-8节.ts"
```

转换不会损失画质和音质，几秒内即可完成，并在同一位置生成同名 `.mp4`。
